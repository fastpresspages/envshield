Frequently Asked Questions

Does EnvShield send my environment variables anywhere?

No. EnvShield is strictly zero-telemetry and has zero runtime dependencies. Everything runs 100% locally on your machine or inside your GitHub Actions runner.

How is Shannon entropy used in secret scanning?

Real passwords and API keys typically have high information randomness (entropy >= 4.2 bits/character). EnvShield calculates character frequency distributions to catch unformatted high-entropy credentials.

How can I generate a clean .env.example?

Run npx -p github:fastpresspages/envshield envshield generate .env -o .env.example. EnvShield will mask sensitive tokens while keeping comments and safe configuration defaults.

Is EnvShield free and open source?

Yes. 100% free under the Apache-2.0 license. Maintained by FastPress Labs.
