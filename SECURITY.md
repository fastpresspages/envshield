# Security Policy — EnvShield

## Reporting Security Issues
If you discover a security vulnerability in EnvShield, please email **meetcode99@gmail.com** or open a private GitHub security advisory at `https://github.com/fastpresspages/envshield/security/advisories/new`.

## Scope
- False negatives in secret leak detection signatures.
- ReDoS (Regular Expression Denial of Service) in pattern matching.
- Any unauthorized network access or telemetry (EnvShield is strictly zero-telemetry).
